# Quanto Custa — Dívida Pública

Quanto custa a dívida pública do Brasil: dívida bruta e líquida, juros pagos, composição, vencimentos,
projeção e o balanço dos bancos e financeiras que aplicam em títulos. Dados oficiais do **Banco Central**,
atualizados todo dia por um robô (GitHub Actions).

Site: https://quantocustaum.com/quanto-custa-divida/

- `atualizar.py` — robô (gera `docs/dados/*.json`)
- `coletor/` — leitura das fontes (SGS, Demab, Focus, IF.data)
- `docs/` — o site (GitHub Pages)
